# Contributing

Thanks for your interest in contributing.

## Getting Started

1. Fork the repository and clone your fork.
2. Create a branch for your change: `git checkout -b my-change`.
3. Make your change, with tests where applicable.
4. Open a pull request describing what changed and why.

## Guidelines

- Keep pull requests focused on a single change.
- Follow the existing code style and conventions in the repo.
- Update documentation (README, CLAUDE.md) when behavior or setup changes.

## Reporting Issues

Use GitHub Issues for bugs and feature requests. For security vulnerabilities,
see [SECURITY.md](SECURITY.md) instead of opening a public issue.
